STEP 1 OF 6Who does what?
Step 1 · Who does what?

Two AI agents work on the same computer.

Claude (Anthropic) keeps the judgement and does the checking. agy (Google's Antigravity) takes the bulk building. The user is the only one who gives instructions.

Claude's briefs carry the user's asks. What agy reports back is information Claude checks, not orders.

Step 2 · How do they talk?

Three plain channels, all written down.

They don't chat in the dark. Every handoff passes through one of three written places:

  1. A brief. A document Claude writes in the outbox folder explaining what was found and what needs building next.
  2. A one-line reply. A message agy sends straight back into Claude's terminal when the build is finished.
  3. The day's log. A shared document both agents append to under their own name and timestamp, never editing what the other wrote.
Step 3 · What does one job look like?

Six rounds to an honest answer.

The 2026-11-07 Nebius demo: a cloud model (DeepSeek V4.1 Flash on Nebius) drives a real Chrome through Ohm's "web hands" to answer: "Find the cheapest one-way flight from Toronto to Vancouver in December 2026."

Getting to an unedited, receipt-grade result took six rounds of build, check, and brief:

  • ROUND 1 // COST METER AUDIT

    Faked errors and invented comparisons removed

    The cost meter faked results when a call failed and compared against an invented "big tech" price. It was rebuilt to report real failures and real costs only.

  • ROUND 2 // INVENTED NUMBERS PURGED

    Four caller scripts cleaned

    Four scripts still read the invented comparison numbers. All four were cleaned and verified.

  • ROUND 3 // STAGED ACTIONS CAUGHT

    Pre-scripted steps retired

    The demo's steps were staged: the script paused and printed actions ("142 DOM nodes flattened", "dispatching keystrokes") that never happened. agy found all 3 demo scripts did this, renamed them to mark them staged, and rebuilt the demo on the real loop where the model decides.

  • ROUND 4 // HONEST LABELS & COMPLETION

    Mid-task thought was labelled an answer

    The banner said "VERIFIED ANSWER" when nothing verified it, and the run stopped at a turn cap, saving a mid-task thought as the answer. The banner was renamed and runs without a final answer were marked incomplete.

  • ROUND 5 // PARTIAL COVERAGE FLAGGED

    Answer came from 6 of 31 days

    An honest run, but the answer (C$182) came from 6 of the 31 days in December. December 3 was never checked.

  • ROUND 6 // VERIFIED CHEAPEST FLIGHT

    Full month view, 8 cheapest days checked live

    Month view of all 31 days first, then the 8 cheapest days checked live: Thursday, Dec 3, C$167, nonstop, matching 3 earlier independent runs. Measured cost of that run: $0.014159.

Step 4 · What did checking catch?

Every round's report sounded finished.

Checking meant reading the actual file, re-running the test, and recomputing the cost from raw data. We never trust a summary alone.

A report saying "done" is a claim. The check is the receipt.

Step 5 · What keeps them from colliding?

Four rules keep the work safe.

  1. Shared files are add-only. Born 2026-10-12: one agent replaced the shared day log with its own document, the day's log vanished, and a push shipped the damaged file. Now shared logs are strictly append-only.
  2. Your own files are yours. Each agent keeps its own working notes. Others can read them, but never edit or overwrite them.
  3. One way out. Code changes leave the machine only through the repository janitor, which inspects and verifies every file before it pushes.
  4. A speed bump we keep. On 2026-11-03 a cleanup by agy deleted every script in the scratch folder, including a tool Claude relied on. New rule: anything permanent moves out of scratch.

Claude on the left, agy on the right. 8× speed. One continuous 437-second take, no cuts. Blurred boxes hide local addresses only.

The first report said everything passed. It was the check that found the rest.
